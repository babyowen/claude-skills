# 银行业日报模板

## 硬约束

- **总字数不超过1000字**（含标题和落款）
- **数据源**：只从 `/Users/babyowen/.claude/skills/bank-news-collector/data/{YYYY-MM-DD}.json` 读取，不读取其他任何文件
- **准确性**：不编造 JSON 中不存在的事实

## 输出格式

```
📰 银行业日报 | {M月D日}

━━━━━━━━━━━━━━━━

📌 今日要览

{150-200字，2-3句话概括当天核心主题，引用关键数据}

━━━━━━━━━━━━━━━━

📊 行业动态

**{主题1}** {2-3句融合多条新闻的段落}

**{主题2}** {同上}

**{主题3}** {同上}

**{主题4}** {同上}

━━━━━━━━━━━━━━━━

💡 经营启示

{250-350字，以自然流畅笔触分析影响并给出建议，分2-3个自然段}

---
基于 {N} 条新闻 | {sources}
```

## 排版规范

- 用 `━━━━━━━━━━━━━━━━` 分隔三大板块
- 板块标题用 emoji 前缀：📌📊💡
- 小主题用 **加粗**，后接正文不换行
- 数据点保持一致性
- 段落间空一行

## 行业动态写作要求

- 按主题分2-4段，每段用加粗小标题（如 **货币政策**、**同业财报**、**监管动向**）
- 融合多条新闻写成一个连贯段落，不逐条列举
- 每段引用1-2个关键数据点
- 示例：

  > **同业财报** 年报季进入高潮。六大行合计净利1.42万亿均双增，农行增速3.2%居首。股份行分化加剧：浦发净利润增10.5%、不良率降至1.26%，而民生营收虽增4.8%，净利润却下降5.4%。13家A股上市银行中近半数Q4净息差环比持平或回升，行业息差1.42%连续三个季度企稳。

## 经营启示写作要求

- 自然流畅的中文，像银行行长写给管理团队的晨会备忘
- 不用"发生了什么""意味着什么""应该做什么"等小标题
- 不用【】标注优先级，不用项目管理语言
- 直接说观点和建议，穿插数据支撑
- 示例：

  > 净息差企稳是当前最重要的窗口。驱动力在负债端——Q1高息存款集中到期重定价，资金部本周就应梳理3年期以上定期存款到期表，设计阶梯承接方案，目标付息率压降20bp。中信和兴业营收持平却差了68亿利润，费用精算不能再拖。
